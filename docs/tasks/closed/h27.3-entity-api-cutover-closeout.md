# H27.3 Entity API Cutover Closeout

Status: closeout note for the H27 public entity-read API migration.

## Purpose

Record the documentation and handoff outcome of the H27 migration from legacy Scopus-branded entity-read APIs to canonical entity routes.

This document is the current closeout reference for the public author/forum/affiliation entity-read API contract. It supersedes earlier historical notes that treated `/api/scopus/**` as intentionally retained for these three APIs.

## Canonical Public Entity-Read APIs

The supported public entity-read routes are:

- `GET /api/entities/authors`
- `GET /api/entities/forums`
- `GET /api/entities/affiliations`

These routes are the canonical public API for Scholardex-backed author, forum, and affiliation reads.

## Public DTO Naming

The public response contract naming for these APIs is:

- `ScholardexAuthorPageResponse`
- `ScholardexAuthorListItemResponse`
- `ScholardexForumPageResponse`
- `ScholardexForumListItemResponse`
- `ScholardexAffiliationPageResponse`
- `ScholardexAffiliationListItemResponse`

This naming now reflects the underlying canonical Scholardex-backed runtime model even though the public route family is `/api/entities/**`.

## Removed Legacy Public Routes

The following legacy public routes are removed and unsupported:

- `GET /api/scopus/authors`
- `GET /api/scopus/forums`
- `GET /api/scopus/affiliations`

The H27 migration does not retain redirects, aliases, or a dual-route compatibility window for these three endpoints.

## Preserved Wire Contract

The H27 cutover preserved the existing public wire shape for the migrated APIs.

Preserved paging envelope fields:

- `items`
- `page`
- `size`
- `totalItems`
- `totalPages`

Preserved item JSON fields:

- authors: `id`, `name`, `affiliations`
- forums: `id`, `publicationName`, `issn`, `eIssn`, `aggregationType`
- affiliations: `afid`, `name`, `city`, `country`

Preserved envelope behavior:

- same authenticated-read posture as before the route migration
- same `ApiErrorResponse` structure for unauthorized and bad-request failures

## Supersession Notes

This closeout supersedes the earlier “keep intentionally” posture for `/api/scopus/**` for author/forum/affiliation entity reads only.

In particular:

- `docs/tasks/closed/h27.1-canonical-entity-api-contract.md` is the archived contract-lock source for the migration intent,
- earlier H17/H23 docs that describe `/api/scopus/**` as the active or intentionally retained contract remain historical evidence,
- those historical docs are not rewritten in place,
- this closeout is the current source of truth for the shipped public entity-read API state.

## Out Of Scope

This cutover note does not change or supersede:

- `/api/rankings/wos`
- publication APIs
- admin MVC routes
- user MVC routes

`/api/rankings/wos` remains intentionally out of scope for H27.
