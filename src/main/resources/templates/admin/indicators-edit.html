Scoring rules
  • Use `*` for any year.
  • Use explicit ranges like `2017->2019,2021->2023`.
  • Use exact years or ranges.
  • You may reference item year as `IY` and ranges like `IY-1->IY+3,IY+5`.
  • Available variables include `N` for author count and `S` for publication score.
  • Supported syntax includes `+`, `-`, `*`, `/`, `max(x,y)`, `min(x,y)`, and ternary conditions.
  • Example: `(S > 1.0) ? (3 + 3 * S) : (3 + S)`.
