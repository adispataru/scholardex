Indicator setup

Choose the activity context first, then define the formula using the supported variables and operators listed below.

  • Available variables include `N` for author count and `S` for publication score.
  • Supported syntax includes `+`, `-`, `*`, `/`, `max(x,y)`, and ternary conditions.
  • Example: `(S > 1.0) ? (3 + 3 * S) : (3 + S)`.
